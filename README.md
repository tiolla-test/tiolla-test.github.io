# Портфолио продуктового дизайнера

Сайт-портфолио на русском и английском языках. Сайт собран на Astro, анимации написаны на GSAP, плавная прокрутка сделана на Lenis. После сборки получается папка с готовыми страницами. Сервер с базой данных сайту не нужен.

## Команды

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build
```

Команда `npm run dev` запускает сайт для работы по адресу http://localhost:4321. Команда `npm run build` собирает сайт в папку `dist`.

## Как залить на хостинг

1. Соберите сайт командой `npm run build`.
2. Загрузите содержимое папки `dist` в корень сайта на хостинге через панель управления или FTP.

Если сайт будет открываться не из корня домена, а из подпапки, например `example.ru/portfolio/`, перед сборкой укажите подпапку:

```bash
BASE_PATH=/portfolio npm run build
```

Чтобы ссылка на сайт показывала в мессенджерах картинку и описание, перед сборкой укажите адрес сайта:

```bash
SITE_URL=https://example.ru npm run build
```

Без адреса сайт тоже работает, но в превью ссылок не будет картинки, а карта сайта для поисковиков получится без полных адресов. На GitHub Pages адрес подставляется сам.

## Адреса

| Страница | Русский | Английский |
|---|---|---|
| Главная | `/` | `/en/` |
| Кейс | `/cases/<папка кейса>/` | `/en/cases/<папка кейса>/` |

## Кейсы

Каждый кейс хранится в отдельной папке `src/content/cases/<адрес кейса>/`:

- `ru.md` — текст на русском;
- `en.md` — текст на английском;
- `img/` — кадры кейса.

**Чтобы добавить кейс,** создайте новую папку и положите в неё `ru.md`. Кейс сам появится на главной и получит свой адрес. Название папки станет адресом кейса, поэтому пишите его латиницей.

**Чтобы убрать кейс,** удалите его папку.

**Чтобы поменять порядок,** измените число `order` в начале `ru.md`. Кейсы идут по группам, а внутри группы по возрастанию `order`.

Если `en.md` нет или в нём только заголовок со свойствами, английская версия покажет текст на русском.

### Свойства в начале ru.md

| Свойство | Что задаёт |
|---|---|
| `order` | Место кейса в списке |
| `group` | Группа на главной: `fic` или `mango`. Группы описаны в `src/data/groups.json` |
| `meta` | Подпись под названием кейса в списке ФИЦ Биомед |
| `kicker`, `chip` | Подпись и метка статуса в списке MANGO OFFICE |
| `cover` | Обложка кейса, например `img/01-обложка.jpg` |
| `stops` | Остановки на пути образца, к которым ведёт пробирка при наведении |
| `schema` | Какая схема стоит на месте строки `*Схема…*`: `fic`, `mango` или `qm` |
| `here`, `marks`, `tag` | Что выделить на схеме и какую подпись поставить |
| `schemaCaption` | Подпись под схемой ФИЦ Биомед |
| `figures` | Крупные числа в разделе «Коротко» |
| `live` | Живые прототипы под названием кейса: `rack`, `form`, `ai` |

В `en.md` пишутся только подписи на английском: `meta`, `kicker`, `chip`, `tag`, `schemaCaption`, `figures`. Остальные свойства берутся из `ru.md`.

### Разметка текста

Кейс начинается с названия `# …`, вводного абзаца и строки с ролью и местом работы. После разделителя `---` идут строки досье вида `**Роль.** …`. Разделы начинаются с `## …`.

Кадр вставляется строкой:

```md
![Что на кадре](img/кадр.jpg "**Подпись.** Пояснение под кадром")
```

Если в одном абзаце стоят два кадра подряд, они встанут рядом.

Особые блоки:

- раздел «Коротко»: строки `**Название.** текст` складываются в сетку, рядом встают числа из `figures`;
- раздел «Выводы»: строки `**Вывод.** текст` складываются в карточки;
- два абзаца подряд, которые начинаются с `**Отказалась.**` и `**Выбрала.**`, выводятся как развилка решения;
- ссылка на другой кейс пишется так: `[текст](case:адрес-кейса)`;
- приписка в самом конце кейса: строка `---`, а после неё один абзац курсивом `*…*`.

Если в тексте кейса ошибка, сборка остановится и назовёт файл и причину. Так бывает, если нет названия `# …` или разделов `## …`, группы `group` нет в `groups.json`, ссылка `case:` ведёт на несуществующий кейс или кадра нет в папке `img`.

## Остальные данные

| Файл | Что в нём |
|---|---|
| `src/data/profile.json` | Имя, «Обо мне», навыки, опыт, образование, контакты, палитры. Для главной: годы опыта `facts.years`, крупные числа `numbers` со ссылками на кейсы, подпись в подвале `footer`. Число кейсов и живых прототипов на главной считается само |
| `src/data/groups.json` | Группы кейсов на главной: заголовок, текст, схема |
| `src/data/schemas.json` | Подписи и координаты схем |
| `src/assets/photo.jpg` | Фото на первом экране |
| `public/resume.pdf` | Резюме для скачивания |
| `public/favicon.svg`, `favicon.ico`, `apple-touch-icon.png` | Значок сайта во вкладке браузера и на экране телефона |

## Устройство кода

| Папка | Что в ней |
|---|---|
| `src/pages` | Адреса страниц |
| `src/components` | Главная, страница кейса, блок живых прототипов |
| `src/layouts` | Общая рамка страницы: шапка, меню, палитра, просмотр кадра |
| `src/lib` | Разбор текста кейсов, схемы, адреса и подписи интерфейса |
| `src/scripts` | Анимации, переходы между страницами, живые прототипы |
| `src/styles` | Стили |

Анимацию можно выключить переключателем в шапке или добавить к адресу `?motion=calm`. При системной настройке «Уменьшить движение» сайт сразу открывается без анимации.
